WELCOME TO YOUR DESKTOP

Meet Andrew OS.

A Debian-based Linux desktop with a familiar, streamlined workflow. Open the application launcher, browse your files, connect to a network, and make the desktop your own.

Browse the web

Chromium and Firefox ESR are available from the application launcher.

Find your files

Use Dolphin to access Home, Downloads, removable media, and shared folders.

Personalize

Open System Settings to change display, appearance, keyboard, sound, and other preferences.

VirtualBox

Resize the VM window and enable shared clipboard or folders in VirtualBox settings. Guest integration depends on the installed host version.

Andrew OS is an independent community project based on Debian. It is not affiliated with Google or the ChromeOS project. Use the system updater regularly to receive Debian security updates.
